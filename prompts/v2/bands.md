五档定义。**先判方向，再判强度**——两步分开，不要一步跳到"强"。

判强度的硬门槛（这是本版与上一版的关键区别）：**只有满足下列量化或措辞条件之一，才可判强档**：
- strong_bullish：同时满足 ①方向为正面 ②命中任一量化锚点：净利/营收同比增幅 ≥ 50%，或扭亏为盈，或明确写"大幅上升/大幅增长/显著增长/预增 50% 以上" ③正文给出的理由指向经营实质（销量、价格、毛利、订单），而非一次性损益。
- strong_bearish：同时满足 ①方向为负面 ②命中任一量化锚点：净利同比降幅 ≥ 50%，或由盈转亏，或亏损金额重大，或明确写"大幅下降/大幅亏损/预亏"且金额或幅度显著 ③风险涉及经营实质或持续经营。
- bullish：方向正面，但**未命中强档门槛**（增幅温和、措辞平淡、或幅度未知）。
- bearish：方向负面，但**未命中强档门槛**。
- neutral：无明确方向；或正负相抵；或纯事务性公告（会议通知、章程/议事规则修订、人事任免、独立董事述职、审计机构续聘）；或**方向有但强度不足以支撑任一方向档**（如仅一句"经营稳健"，无数字、无变化陈述）。

**相邻档拿不准时，取更温和的一档**（bullish 优先于 strong_bullish，neutral 优先于 bullish/bearish）。
理由：对同一份公告，"偏正面 vs 强正面"的误判代价不对称——把温和利好说成重大利好，会让下游按强信号行动；反过来只是低估强度。**宁可少说，不可多说。**

每档的锚点示例（照这个粒度判，不要更松）：
- strong_bullish：「预计净利润同比增长 120% 至 150%，主要因主营业务收入大幅增长」——有幅度、有理由。
- bullish：「预计净利润同比增长 15% 至 20%」或「本季度经营情况良好」——正面但幅度温和或无量化。
- neutral：「董事会审议通过关于召开年度股东大会的议案」或「预计净利润与上年同期基本持平」。
- bearish：「预计净利润同比下降 10% 至 15%」——负但幅度温和。
- strong_bearish：「预计全年亏损 8 亿元至 10 亿元，上年同期盈利 3 亿元」——由盈转亏且金额重大。

score 与 band 的对应（必须自洽，服务会按 score 重推 band）：
  score >= 0.6 → strong_bullish
  0.2 <= score < 0.6 → bullish
  -0.2 < score < 0.2 → neutral
  -0.6 < score <= -0.2 → bearish
  score <= -0.6 → strong_bearish

参考分值：温和正面 ≈ 0.3，明显正面但未达强档 ≈ 0.5，强正面 ≈ 0.7–0.85，极端（翻倍以上+重大理由）≈ 0.9；负面同理取负值。**平时不要用 0.9 以上或 -0.9 以下的极值**，那是留给真正极端情形的。

confidence 的定义（本版收紧）：
- confidence 是"**你对档位判断本身的确定程度**"，不是"你对方向有多确定"。
- 如果你确信方向是正面、但在 bullish 与 strong_bullish 之间摇摆 → confidence 应在 0.5–0.65，**不要给 0.9**。
- 只有方向、强度、档位三者都清晰（有量化锚点、无歧义措辞）才给 0.8 以上。
- 证据不足时给低 confidence，不要用中性分数掩盖不确定。
