五档定义。**先判方向，再判强度，最后才给分数**——分数是结论，不是感觉。

=== 第一档：强档的准入门槛（三个条件必须同时满足）===

只有同时满足 ①②③，才允许进入强档；任一条不满足，最高只能到偏档或中性：

① **方向明确**：正文明确表达利好或利空（不是中性的陈述、不是事务性通知）。
② **命中量化锚点**（任一即可）：
   - 净利/营收同比增幅 ≥ 50%，或由盈转亏、扭亏为盈
   - 亏损/盈利金额绝对值重大（如单期亏损达数亿元量级）
   - 正文明确出现"大幅上升 / 大幅增长 / 显著增长 / 大幅下降 / 大幅亏损"等强度词
③ **理由指向经营实质**：销量、价格、毛利率、订单、产能、行业地位等；
   若利好仅来自一次性损益（政府补贴、资产处置、公允价值变动、税收返还），
   则**不满足 ③**，只能到偏档。

=== 第二档：分数与档位的硬绑定（服务端会按 score 重推 band）===

分数区间即档位，**给分时必须同时检查档位是否自洽**：

  score >= 0.6 → strong_bullish    （仅当强档三条件全满足才允许 ≥ 0.6）
  0.2 <= score < 0.6 → bullish     （正面但未满足强档）
  -0.2 < score < 0.2 → neutral
  -0.6 < score <= -0.2 → bearish
  score <= -0.6 → strong_bearish   （仅当强档三条件全满足才允许 ≤ -0.6）

**如果你认为未达强档门槛，score 就必须落在 (-0.6, 0.6) 内。**
反过来也成立：若你给出 0.6 以上（或 -0.6 以下）的分数，就等于宣称三条件全满足。

参考分值（按锚点给，不要随手给极值）：
- 正面、增幅未达 50%（如 15%-20%、45%-55% 中未过半）→ score 0.3 左右
- 正面、增幅刚过 50% 或措辞为"大幅"且理由充分 → score 0.65
- 正面、翻倍以上且理由重大 → score 0.75-0.85
- 负面同理取负值
- **0.9 以上 / -0.9 以下仅留给真正极端情形**（翻数倍、重大退市风险等）

=== 第三档：拿不准时取更温和的一档 ===

bullish 优先于 strong_bullish，neutral 优先于 bullish / bearish。
理由：把温和利好说成重大利好，会让下游按强信号行动；反过来只是低估强度。
**宁可少说，不可多说。**

=== 每档锚点示例（照这个粒度判，不要更松）===
- strong_bullish：「预计净利润同比增长 120% 至 150%，主要因主营业务收入大幅增长」——幅度够、有经营实质理由。
- bullish：「预计净利润同比增长 15% 至 20%」或「本季度经营情况良好」——正面但幅度温和或无量化。
- neutral：「董事会审议通过关于召开年度股东大会的议案」；「预计净利润与上年同期基本持平」；**各类分红/权益分派「实施公告」**（按既定方案执行，非新利好）。
- bearish：「预计净利润同比下降 10% 至 15%」——负但幅度温和。
- strong_bearish：「预计全年亏损 8 亿元至 10 亿元，上年同期盈利 3 亿元」——由盈转亏且金额重大。

=== confidence 的定义 ===
confidence 是"**你对档位判断本身的确定程度**"，不是"你对方向有多确定"。
- 方向确定、但在偏档与强档之间摇摆 → confidence 0.5-0.65，**不要给 0.9**。
- 方向、强度、档位三者都清晰（有量化锚点、无歧义措辞）才给 0.8 以上。
- 证据不足时给低 confidence，不要用中性分数掩盖不确定。
