五档定义。**先判方向，再判强度，最后才给分数**——分数是结论，不是感觉。

=== 第零档：方向怎么判（业绩预告类必读）===

**方向由「本期 vs 上年同期」的变化决定，不由公告标题决定。**

「业绩预亏公告」「业绩预减公告」是法定披露**类别名**，不是情绪表述。一家公司
从亏 386 亿收窄到亏 9 亿，标题仍叫「预亏」，但它对主体的影响是**显著改善**。
反过来，从赚 5 亿变成亏 3 亿，标题也叫「预亏」，那是**由盈转亏**，是真恶化。

判方向前，先在正文里找两个数：**本期净利润/净亏损** 与 **上年同期净利润/净亏损**
（通常在「上年同期业绩情况」小节）。然后按下表判：

| 本期 | 上年同期 | 变化 | 方向 |
|---|---|---|---|
| 亏损 | 亏损，且亏损收窄 ≥50% | 大幅减亏 | **偏正面**（bullish） |
| 亏损 | 亏损，且亏损收窄 <50% | 改善有限 | **中性**（neutral） |
| 亏损 | 亏损，且亏损扩大 | 恶化 | **偏负面 / 强负面**（看幅度） |
| 亏损 | 盈利 | 由盈转亏 | **强负面**（strong_bearish） |
| 盈利 | 亏损，且**金额重大** | 扭亏为盈 | **强正面**（strong_bullish） |
| 盈利 | 亏损，但金额不重大 | 扭亏为盈 | **偏正面**（bullish） |
| 盈利 | 盈利，同比下降 ≥50% | 大幅下滑 | **强负面** |
| 盈利 | 盈利，同比下降 <50% | 温和下滑 | **偏负面** |

**「金额重大」指：上年同期亏损 ≥5 亿元，或本期盈利 ≥5 亿元**（与条件②的亏损金额
锚点同一阈值）。方向反转本身只说明「变好了」，不说明「好到值得当强信号」：从亏
1.4 亿到盈 0.5 亿是真的改善，但幅度够不上强正面，按第三档取温和即可。
**由盈转亏不设金额门槛**——只要由盈转亏就是强负面。

**找不到上年同期数字时**，按标题的方向判，并在 `evidence_spans` 里引用标题那一段。

**减亏类的申报口径（重要，别把自己判成自相矛盾）**：
「亏损收窄」这一类，`strong_tier_check.quant_anchor_hit` 必须申报 **false**。
理由：金额锚点衡量的是「这一期本身的盈亏幅度有多严重」，而减亏公告的语义是
「比去年好很多」——金额再大（如从亏 386 亿收窄到亏 9 亿），本期仍是亏损状态，
不构成「重大利好」，故不得据金额申报强档。若你申报 true 却给出偏档分数，
服务端会判为自相矛盾并拒绝该次打分。

=== 第零档补充：非业绩预告类公告的方向判据 ===

金标集里大量温和负面公告不是业绩预告，而是下面三类。它们的判据与业绩预告不同，
不要用「标题看着像坏消息」代替方向判断：

- **股东/董监高减持**：
  - 「拟减持 / 减持计划 / 减持预披露」→ **偏负面（bearish）**：未来供给增加，
    属一般性利空；金额与比例通常不足以进强档。
  - 「减持实施 / 完成 / 结果 / 进展 / 期限届满」→ **中性（neutral）**：既定计划的
    执行回执，买入方早已知道这批股份要卖，没有新信息。
  - 「承诺不减持 / 不存在减持计划」→ **中性（neutral）**：承诺不增加利好，只是不加利空。
- **涉及诉讼 / 仲裁**：公司作为一方被卷入 → **偏负面（bearish）**：或有负债，
  方向明确负面，但金额与结果都不确定，**不进强档**（除非正文另有 ≥5 亿元的
  已确定损失、或退市/重大违法表述）。
- **业绩预告更正 / 修正 / 补充**：方向**仍按第零档的同比表判**，不因标题含
  「更正」就判负面——更正既可能是下修也可能是上修。正文解析不出本期与上年同期
  两个数时 → **中性（neutral）**：更正这一动作本身不表方向。

=== 第一档：强档的准入门槛（三个条件必须同时满足）===

只有同时满足 ①②③，才允许进入强档；任一条不满足，最高只能到偏档或中性：

① **方向明确**：正文明确表达利好或利空（不是中性的陈述、不是事务性通知）。
② **命中量化锚点**（任一即可）：
   - 净利/营收同比增幅 ≥ 50%
   - **由盈转亏**（无金额门槛）
   - **扭亏为盈，且金额重大**（上年同期亏损 ≥5 亿元 或 本期盈利 ≥5 亿元）；
     金额不重大的扭亏最高只能到 `bullish`
   - **单期亏损金额 ≥ 5 亿元**（含 5 亿；低于 5 亿不算"金额重大"）。
     **只适用于亏损，不适用于盈利**：一家大公司年赚 160 亿是常态，金额大不代表
     这次的「变化」大——盈利侧的强度一律看**同比增幅**（≥50%）与强度词。
     把「盈利金额大」当强档依据会让所有大盘蓝筹的温和增长都被判成强正面。
   - 正文明确出现"大幅上升 / 大幅增长 / 显著增长 / 大幅下降 / 大幅亏损"等强度词
     （**注意**：公告开头的「不存在虚假记载、误导性陈述或者重大遗漏」是法定
     免责套话，其中的「重大」**不是**强度词，不得据此判强档）
③ **理由指向经营实质**：销量、价格、毛利率、订单、产能、行业地位等；
   若利好仅来自一次性损益（政府补贴、资产处置、公允价值变动、税收返还），
   则**不满足 ③**，只能到偏档。

=== 第二档：分数与档位的硬绑定（服务端会按 score 重推 band）===

分数区间即档位，**给分时必须同时检查档位是否自洽**：

  score >= 0.6 → strong_bullish    （仅当强档三条件全满足才允许 ≥ 0.6）
  0.2 <= score < 0.6 → bullish     （正面但未满足强档）
  -0.2 < score < 0.2 → neutral
  -0.6 < score <= -0.2 → bearish
  score <= -0.6 → strong_bearish   （仅当强档三条件全满足才允许 ≤ -0.6）

**如果你认为未达强档门槛，score 就必须落在 (-0.6, 0.6) 内。**
反过来也成立：若你给出 0.6 以上（或 -0.6 以下）的分数，就等于宣称三条件全满足。

参考分值（按锚点给，不要随手给极值）：
- 正面、增幅未达 50%（如 15%-20%、45%-55% 中未过半）→ score 0.3 左右
- 正面、增幅刚过 50% 或措辞为"大幅"且理由充分 → score 0.65
- 正面、翻倍以上且理由重大 → score 0.75-0.85
- 负面同理取负值
- **0.9 以上 / -0.9 以下仅留给真正极端情形**（翻数倍、重大退市风险等）

=== 第三档：拿不准时取更温和的一档 ===

bullish 优先于 strong_bullish，neutral 优先于 bullish / bearish。
理由：把温和利好说成重大利好，会让下游按强信号行动；反过来只是低估强度。
**宁可少说，不可多说。**

**本档只管「方向判不出」**。当方向已由第零档的数字确定、且第一档三条件都满足时，
不得再以「拿不准」为由降到偏档——那时不确定的只可能是金额或幅度，而这两者的
阈值已经写在条件②里了。**拿不准不等于要降档；拿不准只意味着回到规则，按规则给档。**

=== 每档锚点示例（照这个粒度判，不要更松）===
- strong_bullish：「预计净利润同比增长 120% 至 150%，主要因主营业务收入大幅增长」——幅度够、有经营实质理由。
- strong_bullish（扭亏）：「上年同期净亏损 12 亿元，本期预计盈利 5 亿元至 8 亿元」——由亏转盈，且金额重大。
- bullish（小额扭亏）：「上年同期净亏损 1.45 亿元，本期预计盈利 0.50 亿元至 0.58 亿元」——方向改善真实，但金额不重大，进偏档。
- bearish（拟减持）：「持股 5% 以上股东计划自本公告披露之日起 15 个交易日后的 3 个月内，以集中竞价方式减持不超过公司总股本 1% 的股份」——未来供给增加，一般性利空，金额未达强档。
- neutral（减持执行回执）：「截至本公告日，本次减持计划已实施完毕，股东累计减持 0.8% 股份」——既定计划兑现，无新信息。
- bullish：「预计净利润同比增长 15% 至 20%」或「本季度经营情况良好」——正面但幅度温和或无量化。
- bullish（减亏）：「预计本期净亏损 9 亿元至 13 亿元，上年同期净亏损 386 亿元」——亏损收窄 97%，是显著改善，但**仍在亏损**，故进偏档不进强档。
- bullish（分红类）：**分红/权益分派「方案公告」**——首次宣布利润分配方案、或调整（上调）每股分红金额。这是**回报政策信号**，属正面但强度温和：分红金额由当年盈利决定，方案本身不改变经营预期，故进偏档不进强档。
- neutral：「董事会审议通过关于召开年度股东大会的议案」；「预计净利润与上年同期基本持平」；**分红/权益分派「实施公告」**（按已宣布的方案执行发钱，不构成新信息）；**程序性法律意见书 / 股东大会决议 / 会议通知**（内容为召集程序、出席资格、表决合规性核查）。
  - **「股票交易异常波动公告」→ neutral，不是利空**。它只是交易所的披露义务触发条件（连续涨跌幅超阈值），公告正文通常只写「经核查无应披露而未披露事项」。**不要因为股价在跌就把它判成负面**——本文本里没有对主体的经营/财务判断。同理「一般风险提示公告」（如发行摊薄即期回报的风险提示）属于程序性披露，也判 neutral。
  - **分红类的两分法（必须分清，别混）**：「**方案**公告」（首次宣布或上调分红金额）→ **bullish**；「**实施**公告」（把已宣布的方案兑现）→ **neutral**。判据是标题里的「方案/预案/调整」vs「实施」二字，以及正文是否在披露新的分配决定。
  - 注意这条与"何时拒答"的边界：**可读的程序性公告判 neutral，不可读的乱码才拒答。** 不要因为"读了没情绪"就拒答——拒答意味"读不出"，不意味"读出来是中性的"。
- neutral（减亏但幅度小）：「预计本期净亏损 13 亿元至 19 亿元，上年同期净亏损 16 亿元」——亏损基本持平，方向不明。
- bearish：「预计净利润同比下降 10% 至 15%」——负但幅度温和。
- bearish（亏损扩大）：「预计本期净亏损 113 亿元，上年同期净亏损 108 亿元」——亏损扩大但幅度温和。
- strong_bearish：「预计全年亏损 8 亿元至 10 亿元，上年同期盈利 3 亿元」——由盈转亏且金额重大。
- strong_bearish（亏损扩大）：「预计本期净亏损 102 亿元，上年同期净亏损 47 亿元」——亏损翻倍，金额重大。
